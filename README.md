# Проект ДЗ
## Описание:
Проект предназначен для банковских операций, а именно для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.


## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/kostanno/skypro.git
```
2. Установите зависимости:
```
poetry install
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Проверьте домашние задание.
